
# CS19300-Final-Project
This is my CS19300 final project; more information is in the repo.

Here is the Project planning:

Problem: 

I am interested in investing, but sometimes I don't have a baseline to evaluate a share before I do more in-depth research. Also, in volatile companies, I am not able to process data and do research fast enough before the share prices change too much.

Solution:

I want to build a tool that can help give me insights into trading patterns based on factors such as previous earnings, P/E ratios, and average annual growth (taking into consideration dividends). I have been interested in learning about neural networks and the math behind them, so I will probably develop an RNN in Python or Rust (Both are coding languages I enjoy). I care about it because I can learn from the experience of building it and build on my skill set for the industries I want to get into.
